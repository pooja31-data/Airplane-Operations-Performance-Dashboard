# ✈️ Airline Operations Performance Dashboard | 2024-2025

> End-to-end data analysis project to identify patterns in flight performance, delays, cancellations, and revenue.

### 🛠️ Tools Used
- **Python / Pandas** - Data Cleaning & Preparation
- **MySQL** - Data Analysis & KPI Extraction
- **Power BI** - Interactive Visualization

### 📊 Project Overview
This project analyzes airline operational data to identify patterns in flight performance, delays, cancellations, passenger volume, and revenue. The data was first cleaned using Python/Pandas, then analyzed using SQL, and finally visualized through an interactive Power BI dashboard.

### 🔍 Key Analysis
- **KPIs:** Total Flights (8492), Passengers (2M+), Revenue (₹69B), Cancellation Rate (6.19%)
- Revenue & Average Ticket Price Trend
- Flight Volume by Month and Airline (IndiGo: 987 flights - Highest)
- Average Departure Delays (Emirates: 21.75 min - Highest)
- Cancellation Rates by Airline & Month
- Passenger and Revenue Performance by Airline
- Flight Status Distribution

### 🧹 Data Cleaning
The dataset was prepared using Pandas, including:
- Handling missing values
- Removing duplicate records
- Standardizing categorical values (Airline, Status)
- Creating calculated columns for Delay Category
